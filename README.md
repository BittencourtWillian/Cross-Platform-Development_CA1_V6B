                              Cross-Platform Development CA1

Overview

This project contains research and analysis for the CA1 assignment, the proposal is to evaluate three cross-platform frameworks and recommend the best solution for ACME Fintech.

Objectives

- Compare three cross-platform frameworks
- Analyse their strengths and weaknesses
- Select the most suitable framework for the scenario
- Discuss legal, regulatory and ethical considerations

Candidate Frameworks

- Flutter
- React Native
- .NET MAUI

Project Structure

- notes → planning and requirements
- research → framework analysis
- poster → final poster content
